# Security Policy

Thank you for helping keep Woogles and its players safe.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues,
pull requests, or discussions.**

Instead, report them privately through either of these channels:

- GitHub's private vulnerability reporting: use the **Report a vulnerability**
  button under this repository's
  [Security tab](https://github.com/woogles-io/liwords/security/advisories/new).
- Email: [woogles@woogles.io](mailto:woogles@woogles.io)

Please include as much of the following as you can:

- A description of the vulnerability and its impact
- Steps to reproduce, or a proof of concept
- The affected URL, endpoint, or file(s)
- Any suggestions you have for a fix

We will acknowledge your report as soon as we can, keep you updated as we
investigate, and let you know when a fix has been deployed. We are happy to
credit you for the discovery once the issue is fixed, if you would like.

## Scope

This policy covers the code in this repository and the services running at
[woogles.io](https://woogles.io).

When testing, please:

- Only use accounts you own or have explicit permission to use.
- Do not access, modify, or delete other users' data.
- Do not degrade the service for others (no denial-of-service, spam, or
  automated high-volume testing).
- Give us a reasonable amount of time to fix the issue before disclosing it
  publicly.

## Bug bounty

Woogles is run by Woogles Inc, an entirely volunteer-run 501(c)(3) non-profit.
Because of this, we are unable to offer a bug bounty or any monetary rewards for
vulnerability reports. We are nonetheless very grateful for responsible
disclosure, and are happy to publicly acknowledge your contribution.
